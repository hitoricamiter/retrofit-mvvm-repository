## # Retrofit MVVM Movie App

Это Android-приложение на Kotlin для просмотра популярных фильмов с использованием **The Movie Database (TMDb) API**. Приложение реализовано с использованием архитектуры **MVVM** и библиотеки **Jetpack Paging** для загрузки данных с пагинацией.  

---

## Особенности проекта

- Получение списка популярных фильмов через **Retrofit**.
- Поддержка **пагинации** с помощью `Paging 3`.
- Отображение постеров фильмов с использованием **Glide**.
- Детальный экран фильма с отображением названия, языка и постера.
- **Swipe-to-refresh** для обновления списка.
- Адаптивная сетка `RecyclerView` (2 колонки в портретной ориентации, 4 колонки в ландшафтной).
- Чистая архитектура **MVVM**:
  - `Repository` → работа с данными.
  - `ViewModel` → управление состоянием UI.
  - `PagingSource` → загрузка страниц.
  - `Adapter` → отображение данных в `RecyclerView`.

---

## Технологии и библиотеки

- **Kotlin** — основной язык разработки.
- **Retrofit 2** — работа с HTTP API.
- **Gson** — парсинг JSON.
- **Paging 3** — загрузка и отображение страниц данных.
- **Glide** — загрузка изображений.
- **ViewModel & LiveData** — управление состоянием UI.
- **Coroutine Flow** — асинхронная обработка данных.
- **SwipeRefreshLayout** — обновление списка свайпом.
- **RecyclerView** с GridLayoutManager.
- **Parcelize** для передачи объектов между Activity.
